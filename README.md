# Scan Collect Worth

I want to make a TCG/Sports Card/Collectible App with a built in live scanner that allows people to view their collection value. The appeal will be a broader selection of collectables- so there will be cards with subcategories TCG, sports, etc and sub-sub categories like pokemon, baseball, etc. Another category would be stamps, a third would be coins. Id probably add more but the core function would be the live scanner along with APIs to, for example, TCG and ebay to see price info across different items and item conditions.
